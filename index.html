Projet Job Board — Travail en équipe

Ce projet en équipe consistait à concevoir un site d’offres d’emploi complet, de la base de données à l’interface utilisateur. Nous avons construit une API REST respectant les conventions HTTP (`GET`, `POST`, `PUT`, `DELETE`) et la logique CRUD. Chaque annonce pouvait être consultée sans rechargement grâce à un affichage dynamique. Les utilisateurs pouvaient postuler via un formulaire, créer un compte et accéder à une interface personnalisée. Un espace administrateur gérait la création, suppression et mise à jour des données.
Ce projet m’a permis de renforcer mes compétences en :
conception de bases de données relationnelles,
développement d’API REST et logique backend,
communication front-end / backend via fetch,
travail collaboratif et gestion de projet,
documentation et présentation d’un projet complet.

Projet Universitaire : Étude sur les Pesticides

Ce projet de recherche portait sur l’analyse des données relatives aux produits phytosanitaires utilisés en France. Nous avons manipulé de grandes bases de données pour comprendre l’impact des politiques publiques sur la vente de pesticides. À l’aide du langage R, j’ai effectué le nettoyage, la transformation et la visualisation des données sous forme de graphiques et modèles statistiques. Cette étude m’a permis de renforcer mes compétences en manipulation de données, modélisation statistique et interprétation de résultats dans un contexte environnemental concret.

Projet Universitaire : SNCF Data

Ce projet visait à récupérer et analyser des données issues d’une API SNCF à l’aide du langage R. Nous avons extrait les informations du site, construit une base de données et appliqué des traitements statistiques pour identifier des tendances de trafic et de performance. Ce travail m’a permis de comprendre concrètement le lien entre acquisition de données, analyse et interprétation statistique, tout en consolidant mes compétences en R, API et data cleaning.
