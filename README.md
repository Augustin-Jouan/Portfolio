# Portfolio Personnel - Augustin Jouan

**Note :** Ce projet est actuellement une **première ébauche** et est sujet à des améliorations futures.

## Description

Ce projet est un site web portfolio statique conçu pour présenter le profil académique, les expériences professionnelles et les projets techniques d'un étudiant en Pré-MSc à Epitech (Promo 2028).

L'interface met en avant un parcours spécialisé vers l'Intelligence Artificielle et la Cybersécurité, ainsi qu'une licence MIASHS. Le site est conçu pour être responsive et interactif, permettant aux recruteurs et visiteurs de naviguer aisément entre les différentes sections.

## Stack Technique

Le projet est développé avec des technologies web standards sans dépendance lourde :

* **HTML5** : Structure sémantique de la page.
* **CSS (Tailwind CSS)** : Framework CSS utilitaire chargé via CDN pour le design et la mise en page responsive.
* **JavaScript (Vanilla)** : Gestion de la logique front-end (menus latéraux, modales, interactions dynamiques).

## Fonctionnalités Principales

1. **Navigation Fluide** :
    * Menu de navigation fixe en haut de page.
    * Barres latérales rétractables pour le formulaire de contact et les liens vers les réseaux sociaux.

2. **Section Parcours (Bio)** :
    * Affichage sous forme de cartes interactives.
    * Système d'expansion des cartes pour afficher les détails de chaque expérience (Licence, Séjour en Irlande, Epitech, Jobs étudiants) sans changer de page.

3. **Section Projets** :
    * Présentation des projets techniques (Job Board, Étude R sur les Pesticides, SNCF Data).
    * Vue détaillée accessible au clic pour approfondir les spécifications techniques et les compétences acquises.

4. **Formulaire de Contact** :
    * Intégration d'un formulaire utilisant la méthode `mailto` pour l'envoi direct d'emails.

## Installation et Utilisation

Puisque le projet utilise Tailwind CSS via un CDN, aucune installation de gestionnaire de paquets (npm/yarn) n'est nécessaire pour visualiser le site.

1. Clonez ou téléchargez le dépôt.
2. Assurez-vous d'avoir une connexion internet active (nécessaire pour charger le script Tailwind CSS).
3. Ouvrez le fichier `index.html` dans n'importe quel navigateur web moderne.

## Structure du Projet

* `index.html` : Point d'entrée principal contenant la structure et le contenu.
* `script.js` : Contient les écouteurs d'événements pour l'ouverture des menus et l'affichage des détails (cartes).
* `img/` : Dossier contenant les ressources graphiques (photos de profil, logos, fonds d'écran).
